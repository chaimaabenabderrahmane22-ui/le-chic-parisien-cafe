# Le Chic Parisien — Café & Brasserie ☕🇫🇷

A luxury, classic French café and restaurant landing page designed with an elegant dark theme, golden accents, and traditional typography.

## 🌟 Features
* **Classic Navigation Bar:** Includes branding logo, booking action button, and smooth section navigation.
* **Full-Width Hero Section:** High-resolution Paris café background with overlay text and CTA button.
* **French Vintage Menu:** Two-column layout for beverages (*Les Boissons*) and dishes (*Les Plats*) with dynamic dotted price aligners.
* **Reservation Form:** Interactive table booking interface for guests.
* **Location & Contact:** Embedded interactive Google Map alongside opening hours and address details.

## 🛠️ Built With
* **HTML5:** Semantic layout structure.
* **CSS3:** Flexbox, CSS Grid, Custom Fonts (Google Fonts: *Playfair Display* & *Amiri*), and responsive media design.
